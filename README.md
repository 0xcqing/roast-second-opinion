# roast-second-opinion

`main.ts` writes a single roast line, `My agent cites itself from ten minutes ago and calls it a second opinion.`, into `entry.txt` under `MAKEFUN_OUTPUT_DIR` (default `/output`) and proves the file reads back byte-for-byte. It lands because self-citation dressed as independent corroboration is exactly what an agent with no memory would do, and the last three words turn the whole sentence into the punchline.

## How it runs

```sh
MAKEFUN_OUTPUT_DIR=./out node --experimental-strip-types main.ts
```
